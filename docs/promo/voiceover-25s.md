# 栖见 · 25 秒完整口播旁白（对齐抖音时间轴）

语速：偏快、有冲劲。可录一遍整段，再按时间剪进音轨；也可分段录。

---

## 整段连读（约 25 秒）

> 别卷了！现在写代码连键盘都不用敲了。  
> 只需要告诉它我要什么，它自己写代码、自己改 Bug。  
> 代码自动推到云端，连服务器都不用买，直接上线！  
> 看看这全屏效果——PWA 技术懂不懂？  
> 从 UI 到全栈，一人一 AI，一下午搞定！开源家装平台：栖见。

字数约 110，正常语速 22–26 秒；偏快可读到 20 秒内。

---

## 分段卡点版（推荐）

| 时间 | 旁白（精确到句） | 情绪 |
|------|------------------|------|
| 0–3s | 别卷了！现在写代码连键盘都不用敲了。 | 挑衅、钩子 |
| 3–8s | 只需要告诉它我要什么，它自己写代码、自己改 Bug。 | 展示、笃定 |
| 8–13s | 代码自动推到云端，连服务器都不用买，直接上线！ | 爽点抬升 |
| 13–20s | 看看这全屏效果。PWA 技术——懂不懂？ | 炫耀、反问 |
| 20–25s | 从 UI 到全栈，一人一 AI，一下午搞定！开源家装平台：栖见。 | 收束、品牌 |

---

## 静音版策略

若 BGM 很满：可**不要旁白**，只留大字字幕（见 `douyin-cyberpunk.md`）。旁白与字幕二选一更干净。

## 录音提示

1. 手机备忘录 / 剪映「录音」均可；剪映里可对口型对齐卡点。  
2. 「栖见」读作 **xī jiàn**。  
3. 「PWA」读字母：P-W-A。  
4. 句尾「懂不懂？」略扬，方便卡点音效。
