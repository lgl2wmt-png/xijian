## 正文（可直接复制）

一个人 + 一个 AI，把「家装决策」做成了开源产品：**栖见**。

### 我做了什么
- 前端：Vite + React，灵感首页 / 案例 / 设计师 / 进度  
- 高光：**决策星图**（预算、约束、冲突一眼看清）  
- 上线：GitHub → Vercel 一键部署  
- 手机体验：PWA，Safari 添加到主屏幕，全屏像原生 App  
- 数据：静态站默认 Mock，不用买服务器也能完整体验  

### 你怎么复现（最短路径）
1. 打开线上站（评论区 / 主页放链接）  
2. iPhone 用 **Safari** → 分享 → **添加到主屏幕**  
3. 点桌面图标，滑到「星图」看效果  
4. 想学代码：GitHub 搜 **xijian** 或点主页置顶  

### 工具链（方便收藏）
`Cursor Agent` → 写码改 Bug  
`GitHub` → 版本与开源  
`Vercel` → 静态 PWA 上线  
`PWA` → 免上架、免 688  

### 一句实话
Debug APK / 上架商店是另一条路；想先让人「摸到产品」，PWA 性价比最高。
